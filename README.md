# Scheduler — Android-клиент

Мобильное приложение планировщика расписания. Работает в паре с собственным бэкендом: [Sheduler-2-server](https://github.com/FunnCo/Sheduler-2-server).

## Возможности
- Просмотр расписания по неделям
- Повторяющиеся шаблоны событий и разовые события, заметки к ним
- Ручное формирование расписания на произвольное число недель

## Стек
Kotlin · MVVM · Retrofit/REST · собственный бэкенд на Spring Boot
